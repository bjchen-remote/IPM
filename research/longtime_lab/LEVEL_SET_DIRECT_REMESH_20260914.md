# 从 level set 直接构造 REMESH 轴：隔离原型

当前 version-5 规划器在每个节点级别测试 70 个 X 参数、4 个 Y 参数；必要时再把 X 参数扩至 500 个，最多返回 3 对实际迁移候选。这是几何参数搜索，不是从特征尺度求解一次逆映射。

`mesh_level_set_direct_candidate` 是研究级无 LU、无迁移原型。它只读现有接受态的 90% 墙面核心区间、左侧前沿区间和 90% 竖直宽度，输出一对轴与全轴质量报告。设核心和前沿目标格数为 `Nx_core`、`Nx_front`，则

```text
h = min(core_width / Nx_core, front_width / Nx_front) / xPadding
fineCells = ceil(core_width / h)
leftFineFraction = (peak_x - min(core_left, front_left)) /
                   (max(core_right, front_right) - min(core_left, front_left))
roundingCells = max(8, ceil(log(maxAdjacentRatio) / maxLogCurvature))
```

X 仍调用已维护的等宽核心加圆滑几何过渡构造器，并保持精确 `x=±1`；Y 调用单参数 `roundedGeometricAxis`，通过标量二分满足竖直核心格数。检测全部现有几何质量门和核心/前沿预测门。现有 X 构造器内部仍扫描整数左右分格；此原型消除了外层 70/500 项参数枚举，但不是最终的最小复杂度实现。

旧 C 行是把新直接几何公式应用于旧冻结场的反事实筛选；其 Y 使用几何级数轴，不属于该旧检查点原有的候选身份，不能据此续算旧策略。

若要成为生产策略，应把触发输入固定为同一批 level-set 交点/宽度及其接受步历史，用当前格数或这些宽度的预测损失决定何时重布；节点级别只由几何容量和启动前预算确定。验收仍需原生场迁移后的核心、峰值、质量和值域门。这个原型尚未在更多箱、更多晚期态或从原始 `t=0` 连续长跑验证，不能替换已冻结检查点的策略版本。
