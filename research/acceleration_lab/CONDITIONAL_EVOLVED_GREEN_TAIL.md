# 有限物理时间的远场尾：条件推导与可拒绝协议

2026-09-09。当前 k8 源的 1/r 主项**可能**在有限物理时间保持，从而给
固定物理锚点的外尾长度率 A/H 一个条件化依据。但仅由速度有界不能
推出这一结论。本文件给出充分的远场速度条件及可测的误差形式；没有
证明这些条件沿真实 IPM 轨迹持续成立，也没有给演化场添加任何初值尾。

## 先纠正密度的径向前提

实际方程由维护 `evolve.rhs`、`field.transport` 和 `field.biotSavart` 给出：

\[
\rho_t+u\cdot\nabla\rho=0,\quad
u=(-\psi_y,\psi_x),\quad-\Delta\psi=\Omega=\rho_x,
\quad u_2(x,0)=0.
\]

这里是连续物理 PDE；映射 WENO、外边界截断、离散壁面及全线 LF 不
自动满足下述连续估计。研究中不能用条件推导掩盖这些离散误差。

原初值是

\[
\rho_0=\tfrac18\log(1+x^8/(1+y^8)),\qquad
\Omega_0=\frac{x^7}{1+x^8+y^8}.
\]

固定 \(0<\theta<\pi/2\) 的射线上，\(r\to\infty\) 时
\(\rho_0\to\tfrac18\log(1+\cot^8\theta)\)，**没有 log r 项**。
在 y 固定的近墙区域，才有
\(\rho_0=\log x-\tfrac18\log(1+y^8)+o(1)\)。角向极限不一致。
因此不能写成适用于整个正象限的 “log r + 有界角函数”。

相比之下，源有一致的齐次主项

\[
\Omega_0=r^{-1}f(\theta)+O(r^{-9}),\quad
f(\theta)=\frac{\cos^7\theta}{\cos^8\theta+\sin^8\theta}.
\]

初值满足 \(|\Omega_0|\lesssim r^{-1}\)、
\(|\nabla\Omega_0|\lesssim r^{-2}\)，但

\[
\rho_{0,y}=-\frac{x^8y^7}{(1+y^8)(1+x^8+y^8)},\quad
|\rho_{0,y}|\lesssim(1+y)^{-1}.
\]

当 x→∞、y=1 时这个纵导数趋向 −1/2。故单独的 \(u=O(1)\) 和
\(\Omega=O(r^{-1})\) 并不能保证 \(u\cdot\nabla\rho=O(r^{-1})\)。
例如一个满足壁面为零但在固定 y=1 为常数量级的有界纵速度就不足；
需要额外的远场壁面结构。这里的反例是对推理条件的反例，不是声称
该速度能由当前 IPM 初值生成。

## 一个足够、但尚未沿 PDE 证明的条件集合

在固定有限物理区间 [0,T]，假定存在经典解；外区 r≥R0 上，存在
可积/有界的时间系数，使下列估计成立：

\[
|u|\le U_T,\qquad |\nabla u|\le D_T/r,\qquad
|u_2|\le D_T y/r,\qquad |\partial_xu_2|\le D_T y/r^2.
\]

所有常数可依赖 T，且不能在接近可能的奇异时刻时假定仍统一有界。
取 r 远大于初始外区尺度和有限时间最大位移。沿反向特征线，有限
位移与上述壁面界给

\[
X_0=x+O_T(1),\quad Y_0=y[1+O_T(r^{-1})],\quad
\partial_xX_0=1+O_T(r^{-1}),\quad
\partial_xY_0=O_T(y/r^2).
\]

这是对反向流及其 Jacobian 的 Gronwall 估计；需要上述速度一阶导数
条件，不能仅从“粒子位移有界”推导 Jacobian 的衰减。
利用 \(\rho(t)=\rho_0(X_0,Y_0)\) 和初值的明确导数界，可得

\[
\rho(t)-\rho_0=O_T(r^{-1}),\qquad
\Omega(t)-\Omega_0=O_T(r^{-2}).
\]

第二式的关键是
\(\Omega(t)=\rho_{0,x}\partial_xX_0+\rho_{0,y}\partial_xY_0\)：
纵项虽含近墙 O(1) 的 \(\rho_{0,y}\)，但乘上
\(O_T(y/r^2)\) 后仍是 \(O_T(r^{-2})\)。于是 **在这些条件下**，
源的 \(f(\theta)/r\) 主项保持。

直接微分 PDE 同样显示需要这一条件结构：

\[
\Omega_t=-u\cdot\nabla\Omega-(\partial_xu_1)\Omega
-(\partial_xu_2)\rho_y.
\]

末项不应遗漏。只拟合 wall 或固定角扇区不能验证整个积分外区的界。

这套假设与初始齐次源相容：在双奇正象限 Dirichlet 几何中，齐次
模型 \(-\Delta[r p(\theta)]=r^{-1}f(\theta)\) 化为
\(-(p+p'')=f\)、p(0)=p(pi/2)=0。该角区 Dirichlet 频率为 2n，
不含造成 r log r 共振的频率 1；其速度是零次齐次、导数为 -1 次。
由边界 p(0)=0 得 u2=O(theta^2)，与上述壁面界相容。这只说明主项
模型没有立即矛盾，**并未证明非线性余项、非局部耦合及加权界的传播**。

## 条件化的尾误差与适用尺度

沿用 `GREEN_INITIAL_SHELL_CONTROL.md` 的精确 wall kernel、固定物理
anchor a 及 D_H=[0,H]×[0,H/2]。若已知
\(|\Omega(t)-\Omega_0|\le M_T/r^2\)，则外尾满足

\[
T_t(H)=\frac{A}{H}+O(M_T/H^2)+O(a^2/H^3)+O(H^{-9}),
\qquad A=0.424769906167223\ldots .
\]

O(M_T/H²) 来自 r^-2 的演化源差、r^-2 的墙核及面积元 r dr。
它可能比初始核修正 H^-3 更大，不能在 t>0 继续套初始误差阶。
若只能得到带 log r 的加权界，余项也会相应出现 log H/H²；若速度或
远场梯度条件失败，则连该余项形式也没有依据。

H 必须真正位于物理远场：大于初值长度 1、锚点尺度、外区 R0 以及
有限时间位移尺度。固定计算盒在动态重标度下会对应不断缩小的物理
盒，**计算坐标 H 很大并不自动满足这个条件**。有限盒本身无法检验
盒外未知场，因此有限环带测量只能作为拒绝/支持诊断，不是传播证明。

## Cx/Comega 的单位：各向同性、无平移

维护 `field.reconstructPhysical` 的约定为

\[
X=C\,x,\quad Y=C\,y,\quad C=C_x=C_y,\quad
\widetilde\rho=C_\omega\rho,\quad
\widetilde\Omega=\frac{C_\omega}{C}\Omega(X/C,Y/C),\quad
\widetilde u=C_\omega u,\quad dt/d\tau=C_\omega/C.
\]

第一行的 x/y 是物理坐标；此节 X_shift=0。代入齐次源后

\[
\widetilde\Omega(\tau,R,\theta)
=\frac{C_\omega f(\theta)}{R}
 +O\!\left(\frac{C_\omega C M_T}{R^2}\right)
 +O\!\left(\frac{C_\omega C^8}{R^9}\right).
\]

所以计算坐标中的领先源尾幅值是 **Comega**，不是 Comega/C；后者
必须与源径向坐标的 C 一并转换。若计算盒 Hc、固定计算 anchor aX，
则 Hp=Hc/C、a_phys=aX/C，且

\[
\delta c_l^{\rm canonical}
=\frac{C_\omega A}{H_c}
+O(C_\omega C M_T/H_c^2)
+O(C_\omega a_X^2/H_c^3)
+O(C_\omega C^8/H_c^9).
\]

乘 dτ/dt=C/Comega 后，首项为 C A/Hc=A/Hp，正是物理长度率单位。
这些是**遗漏 Green 外尾的率量级**，不是要直接添加到 C 公式的源项。
各向异性、非零平移或变长宽比需按完整物理映射重新计算域和核，不能
仅搬用这里的 A。fresh epoch 本身只登记物理时间偏移；空间坐标始终
由真实轴、尺度和位移重建。若研究另做了坐标/幅值重新定标，须依据
那项独立保存的变换，不能把时间 epoch 误当成空间转换因子。

## 纯积分 MMS 与未来早期真实控制

已准备的纯积分入口 `ipm_accellab_test_conditional_tail(out)` 使用

\[
\rho_\epsilon=\rho_0+\epsilon\frac{x^2}{(1+x^2+y^2)^{3/2}}.
\]

该附加密度是 O(1/r)，其源是
\(\epsilon[2x/(1+r^2)^{3/2}-3x^3/(1+r^2)^{5/2}]\)，
即 \(\epsilon(2\cos\theta-3\cos^3\theta)/r^2+O(r^{-4})\)。
它是解析测试场，**不是未加 forcing 的真实 IPM 解**。预登记
epsilon=0/.1/.2、H=8/16/32/64/128、Gauss64/128/256。检查：

- 独立阶次尾积分差≤1e-11；epsilon 线性只验证积分算子。
- H²×(T_epsilon−T_0)/epsilon 趋向由角积分独立算出的常数 B；
  其首个误差为 O(H^-2)，末次误差比登记为 [3.8,4.2]。
- C=.5/1/2 与 Comega=.5/1/2 的九个物理等价坐标下，使用完整变换后
  的解析源、anchor 和盒，恢复物理率应在相对 1e-11 内一致。

即使全部通过，也只验证积分公式和单位。下面的早期真实控制**尚未
执行**，必须独立新标签，不能把含新外尾近似的研究状态写成旧原生 CP：

1. 首先在同一小网格、同一初始解析采样、同一离散矩阵上，分别使用
   原 Green 边界和“原边界加已知外尾的完整 Green 迹”。只改变边界
   截断近似；原输运、规范公式、CFL、积分器和时钟全部保持。
2. 外尾使用完整 Green 核积分，不能把标量 A/H 直接加到 c_l，也不能
   在整个人工边界上使用仅对固定内点成立的 xy A/H 近场展开。边界
   目标贴近外源接口的可积 log 奇异必须分区/变换处理；另用独立
   求积验证完整 traces、镜像对称和零底墙。建议先注册 rate绝对
   1e-11、trace相对1e-10（近零处配绝对预算）的求积门，再看 PDE。
3. 先只做 t=0：与精确全初值 Green 卷积、原近似截断边界和精确截断
   边界分别比，分开外尾、边界求积/压缩和 FD 误差。随后才研究很短
   的共同**物理**时间窗；例如 t≤.01，至少49/65两档以及独立倍箱
   对照。当前没有启动这些计算，也未给这组网格准入资格。
4. 在共同原生 inner nodes 与固定物理 holdout 检查 rho、Omega、两分量
   速度、真实 C 率和完整 RHS，保留双方实际 PPrime。外圈同时测
   r²|Omega(t)−Omega0|、r|grad u|、r|u2|/y 和 r²|u2_x|/y；y=0 使用
   解析/一致单侧极限，不直接除零。还要报告相关量的方向分布和原生
   间隔，避免只选择好看的角区。
5. 接受进一步研究的必要条件是：求积误差比观察改善至少小10倍，
   独立时步减半与空间加密误差也小于改善且趋势一致；core/holdout/
   尾部速度和原硬门同时通过。若只降低规范率差、改动小于空间误差，
   或外区加权量不受控，则拒绝“改善已证”的结论。有限角环观测始终
   不能单独证明全域远场条件。

这个路线改变的是非局部求解的外尾边界近似，不是瞬时 C 规范。它还
可能受到人工输运边界未知入流的影响，Green 尾改善不自动修复该问题。
现有长期 native 轨迹、旧失败、B/C/D/E 终点门和 t0 盒积分结论不变。

## 完整边界模板的条件性成本

若保持各向同性、零平移、固定计算盒与轴，则完整领先外源为
`Comega * f(theta)/R`。Green 积分对源线性，所以对每个实际边界查询点
q_j，有

\[
\widetilde b_{{\rm tail},j}(\tau)
=C_\omega(\tau)b^0_{{\rm tail},j},\qquad
b^0_{{\rm tail},j}=\iint_{D_c^{\rm exterior}}G(q_j,S)
 \frac{f(\theta_S)}{|S|}\,dS.
\]

因此在**接受这项外尾近似的前提下**，每张新网格只需做一次完整边界
纯积分预计算，以后每个 RHS 是标量乘和加入原 Green 迹，不需要每步
重积分。固定 kappa=1 的 Poisson LU 仍可复用。由于离散 Dirichlet 注入
也线性，理论上还可预先生成与该网格成对的内部 RHS 边界增量；是否
这样实现须另审浮点组合顺序和缓存失效，当前尚未写入求解器。

模板须包含 left/right/top 的全部实际查询点，bottom=0；它不能用内点
`xy*A/Hc` 近场展开代替。网格/盒/对称模式/kappa/平移或核规则改变时
需要重新验证或失效；不能仅靠节点数作为缓存键。尺度 C 改变但上述
几何不变时，C 已被 -1 次齐次性消去，只剩 Comega 乘子。

未知演化余项的误差量级须区分观察位置：若
`|delta Omega| <= Comega*C*M_T/R²`，上文
`O(Comega*C*M_T/Hc²)` 仅是**固定内部锚点长度率**的误差。对与盒一起
缩放的人工边界点 q=Hc*qhat，Green 核为零次齐次，故完整 psi trace
一般只有 `O(Comega*C*M_T)`，边界速度为
`O(Comega*C*M_T/Hc)`。不能把内部率的 Hc^-2 预算用于整个边界迹。
这些仍是给定源余项界后的积分估计；在边界接触外源的点要处理可积
核奇异，不能假定边界各阶导数都具有相同的统一误差界。

这项成本观察使**早期、已具物理远场覆盖**的完整边界 MMS 有研究价值。
它不是对晚期缩小物理盒的准入许可，也没有证明会加速 Profile 收敛。
