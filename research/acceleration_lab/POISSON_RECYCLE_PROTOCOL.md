## 为什么先不做时间变换或空间多率

令完整状态 y 包含 rho 和全部尺度/时钟，原方程为 dy/dtau=F(y)。若用
ds/dtau=1/q(y)>0，则 dy/ds=qF、dtau/ds=q。冻结一个局部步，原输运
CFL 速率 R 同时变为 qR，因此 ds≤CFL/(qR)，对应的 dτ≤CFL/R。
线性慢模态衰减率也乘 q；这不是每个稳定显式步的免费收益。状态依赖 q
还要求一致推进所有尺度，事件和误差控制不会因此消失。该推导是局部
冻结速率的结论，不假装涵盖任意隐式积分器。

空间不同点使用不同的 q(X,Y) 而保留一个物理时钟，一般改变原 PDE。
真正的局部子步法需要共同时间的通量与非局部速度，不能把各点独立快进
后拼接。当前速度通过全域 Poisson/Green 场耦合，WENO 的全线 LF alpha
也耦合一整条线；旧余速分裂已经显示不能直接相加。因此不把未经定义的
“内核快进、外部冻结”列为可执行候选。

## 唯一候选：固定 memory=4 的椭圆解预测

固定一个精确相同的网格、kappa=1、边界配置和差分算子 epoch。每次都从
**当前 stage rho** 计算原 source、原 Green 边界与完整内点 RHS b；不能
外推 b，不能复用 Green 源筛选/压缩结果。使用维护源码的原装配分组。

设前五个原生完整回代的内点解为 x[j-5],...,x[j-1]。取 seed=x[j-1]，
四个列向量 V=[x[j-5]-seed,...,x[j-2]-seed]。令

```
D(i,i) = 1 / max_j |A(i,j)|
c = argmin || D*(A*V*c - (b-A*seed)) ||_2
xTrial = seed + V*c.
```

先按 ||D A V(:,k)||₂ 归一化列，再用四列薄 SVD；相对截断固定 1e-10，
原 V 坐标中的 ||c||₂≤32。只算这一候选，无 memory/阻尼扫描。不用
全场残差大小自动调宽物理误差门。D 只定义投影度量，原 A、原 b 和最终
原方程残差都保持。保存低秩/rank-loss、系数、每项失败，不压掉失败样本。

新鲜边界直接嵌回 xTrial，再用维护 Dx/Dy 求速度，以原瞬时代数公式重新
求 c_l/c_omega/c_r，再用原 WENO 完整装配 F。这里没有 P 投影或 restoring。
但是错误速度也可能让其自身代数 P′恰为 0，所以**P′小不是准确性证据**；
必须与同 rho 的真实原生速度、率及完整 F 比较，保存真实 P′的两份数值。

在对照阶段，每个 stage 仍做原 LU 得到 xNative，候选只作旁路观察，
一律不进入后续 rho。这样能先拒绝不可能的候选，不制造新轨迹。
前五个参考和其后所有训练参考都是原生值；由此测得的潜在命中率是乐观
上界，不是闭环复用的真实命中率。SSPRK stage 的评价顺序不能误写成
单调物理时间序列；该代数投影本身不需要按时间排序或插值时刻。

所有 remesh（包括同 N 的轴变化）、node-family 切换、kappa/配置变化和
原二次峰 selector 切换都清空缓存。变 N 不能插值旧解后假装仍是同一个 A。
跨规范 selector 的窗口独立保留，重新完成五个原生解的冷启动。

## 阶段 A：可直接否决的小网格旁路试验

拟用已经存在的 49×25 / 65×33 Gaussian tiny 配置及其**原 quadratic**
方程，不用本目录独立 C1 方程。沿原可信参考采集：

- 光滑窗口 tau∈[0,.032]；另列跨旧模板窗口 [.032,.08]，不得只报前者。
- 时间档 h=.004/.002/.001，最多两网格各 3 条短轨迹；实际原 CFL 优先，
  若该配置不准入就保留失败，不降质量阈值。
- 同一当前 b 比较 xTrial 与 native x，二者拥有相同当前边界。
  真正 IPM 样本至少每个网格/窗口包含 20 个可预测 stage；不足则结论为
  数据不足，不混不同 epoch 填够数量。

每个样本的固定必要门：

1. 原全局残差≤5e-12，分量后向误差≤5e-14；同时保留原生值。任何
   原生产更严的门仍须满足。这两项不是前向误差认证。
2. 全域速度、同一物理内核和物理尾部两分量速度相对 infinity 误差≤1e-10；
   同当前 rho 的 c_l/c_omega/c_r 误差≤1e-10·max(1,|原率|)。
3. 完整 F 和 F Dx′ 相对 L2/infinity 差≤1e-9；完整 C1 Uτ、固定 smooth
   theta=.5 及 .3/.7 holdout 残差与原值差≤1e-4 相对。真实 P′保留。
   一个零/近零分母只能改报绝对误差和“不可判定”，不能通过。
4. 原 full-box、原 native-FD、同一内核/holdout、尾部速度门都保留，不能
   靠 shape 规范消去错误。固定物理尾窗与全计算域分别命名。

初始旁路准入至少要求两个网格上，每个窗口所有实际尝试满足门，预测
stage 的比例≥50%；所有初始化、selector 和 remesh 冷启动都计入分母。
这里是值得继续研究的苛刻筛选，不是生产准入。若只约束根通过而完整 F、
速度或 shape 不通过，就停止本候选，不接着调参或改规范。

本轮提供的 `ipm_accellab_recycle_shadow(A,B,Xnative,velocityMap)` 仅实现
其中的纯数组投影、原残差和线性速度误差检查；n≤4096。完整 F、C、时钟、
可信性门**没有实现/执行**，其输出 integrationApproved 永远为 false。
调用者须先验证 B 包含每列新鲜边界，Xnative 严格同 A；不能将当前 t0
大网格的稀疏 output history 冒充 stage 解历史。

## 阶段 B：误差预算与成本判断，尚未执行

只有阶段 A 全过，才准备 ≤65×33 的独立研究闭环：保持原 SSPRK54、原
步长选择及全部五个尺度变量，失败回退**原 b 的原 LU 解**。原 LU 对
`b-A*xTrial` 再作全额修正仍需一次回代，不应虚报节省；将近似解用作
direct solve 初猜也不会自动缩短 UMFPACK 工作。这里的收益只能来自可
可靠免去的回代，不是给 direct solve 传了初值。

一个关键未解问题是：运行时不做真 LU，如何认证前向速度误差？单靠
残差、零 P′或间歇抽查不足以保证每个 stage。若只能依靠每次真 LU 验证，
本方法就没有生产收益，应结论为拒绝部署。未来若引入可证明的输出误差
界/廉价纠错，必须另注册其成本和病态反例，不能从这份旁路试验跳过去。

拟定的同物理时间检查点为 t=.025/.050/.075，均使用原物理 clock；
原生 h/2、h/4 参考以同一端点 RHS 的时间 Hermite 对齐，全部尺度同时
处理。给每个量 Q 定义预先固定 baseline 尺度 S_Q、原生两档差 Δ_Q，预算

```
B_Q = max(200*eps*S_Q, min(cap_Q*S_Q, 0.2*Delta_Q)).
```

cap_Q：physical rho=1e-8、gradient/velocity=1e-7、log-scale=1e-8、
clock=1e-10、core/holdout U_t=1e-4。低于舍入包络时只要求处于同一包络，
不得推四阶。原生 h/4 与额外一次 h/8 校验差必须≤0.1 B_Q，否则参考预算
不足，停止而不是扩写通过。全部完整物理字段、尾部速度、原可信历史及
端点到达门都必须过。Δ_Q 只是离散参考敏感性，不是严格 continuum 误差界；
没有 Lipschitz 放大界时，也不能把逐 stage δF 门相加冒充全局误差证明。

统一的预算不从不同 box/时刻的历史 7–14% shape 差推来。新 v2 的空间
误差仍要用它自身同物理时间对照评价；即使回代误差很小，也不能借此
认证主线空间收敛或 Holder/强奇异性。

计时必须包括新 Green、A V/残差、SVD、所有误差门、冷启动/回退和缓存
维护。固定 ABBA 6 轮；同误差、同物理终点下中位整体加速≥1.20，且
每块不慢于原方法，才值得提出后续大网格旁路申请。若回代占比为 p、
实际省略比例为 s、其它新增相对成本为 o，理想时间比为 1-p*s+o；用旧
profile 的 p≈.729、s=.5、o=.05 仅得到假设 speedup≈1.46，并非实测。
