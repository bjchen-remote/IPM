# 原生长跑冻结数据给出的自动网格设计约束（2026-09-13）

目标是从原始物理 `t=0` 启动，在不暂停、不改配置、不人工换网格的情况下推进到更长 canonical 时间，保持已注册的真实场迁移、质量、守恒、规范和 checkpoint 验收。外层相邻格宽比停止阈值是 2；现有自动候选的更严格质量上限是 1.08，二者不可混同。当前节点总上限 310000，晚期使用 641×321=205761 节点。越过 1.08 的未知网格不应仅凭外层阈值 2 宣称合格。

## 已遇到的网格问题和冻结证据

1. 原始零时间数据曾使固定初始候选不足。Version 5 的解析数据预检和有界初始观察回退已在原始 `t=0` 轨迹上验收，后来自动升级 X、Y 到 641×321；不需要在中途重新设定网格。
2. 竖向核心宽度当前取墙面峰值的**离散 X 列**。同轴冻结 checkpoint 的连续二次峰值 X 观察显示，离散列与四列局部 PCHIP 的宽度相对差最大 1.817%（τ10.3–10.6）/2.464%（τ10.7–11.0），核心格数最大差 0.466/0.636。以 0.1 canonical 时间间隔计算的最大负对数割线衰减率，离散列为 0.70171/0.81426，连续列为 0.44444/0.46732，即放大约 1.58/1.74 倍。连续列本身也在下降；这些数据**尚未证明**原决策是错误触发。
3. 早晚四个冻结状态的同预算无 LU 配对审计见 [`evidence/frozen_pair_ratio_20260913.json`](evidence/frozen_pair_ratio_20260913.json)。τ10.3、10.7、11.0 的常规 X/Y 合格试探数分别是 12/2、4/2、4/2；到 τ11.7004 变成 0/2。此时当前 X/Y 核心格数 29.272/33.784，最大相邻格宽比 1.076654/1.075858。注册的一级分层 X 回退提出 3 个候选；第一项在该冻结场上预测 X/Y 核心 34.277/36.800，前沿 38.204，最大格宽比 1.071646。第三项预测 X 核心 35.201，但最大格宽比 1.074248，呈现「多留核心格数」与「更均匀格宽」的实际权衡。冻结提案不包含场迁移验收或未来存活时间。
4. 主 H8 原生长跑随后**确实**在 τ11.932175465、step11533 从同一 `t=0` 轨迹自动完成第 35 次重布。已验签事务选择一级分层回退 `xScheduleIndex=82, yTrialIndex=4`，真实场迁移通过，迁移后核心格数 32.853/36.972、X/Y 格宽比 1.072844/1.057942。τ12.0002499 的已验签 checkpoint 保持 641×321、35 次重布，核心 30.780/36.208、物理梯度最大值 115.889。这里有真实自动回退成功的证据，但并不保证下一次更窄核心也有候选。
5. H8 的远边界源/速度指标在 τ12.0 仍为 0.02281/1，超过 0.01 告警阈值。无论网格如何优化，当前结果还不能宣称大物理箱、空间或时间收敛，更不能宣称无穷时间 Profile 或强奇性。

利用**仅在 τ11.7004 前**的同网格 τ11.4、11.5、11.6、11.7 观察，X 核心最大分段负对数衰减率为 0.48141，连续峰值 Y 为 0.31913。以原 `26/26` 核心触发阈值估计，当前网格的 X 首达时间是 τ11.946607；留出的原生触发发生于 τ11.932175，误差 0.01443。对 τ11.7004 提出的三个候选作**仅几何/冻结率**估算，X=82、81、89 的瓶颈可用时间分别为 0.5741、0.5756、0.6293 canonical 单位；X=89 相比最小格宽比的 X=82 多约 0.0552（9.6%），代价是最大格宽比由 1.071646 增至 1.074248，仍低于 1.08 注册质量门。Y 的估算寿命均为 1.089，故这些候选由 X 约束。完整数据见 [均摊寿命审计](evidence/amortized_mesh_ratio_20260913.json)。这揭示了“最小瞬时格宽比”和“较长重布间隔”的 Pareto 权衡；冻结 X89 已通过真实场迁移审计，但它在实际请求时刻不再是前三个候选，不能直接替换正式首选项（[冻结迁移审计](evidence/alternative_transfer_tau117_20260913.json)）。

在**实际请求** τ11.932175465、step11533，重放已验签来源态的原生推进与规划，X82 的迁移审计逐值等于主轨道第35次事务。该时刻前三个 X 候选为 82、81、90。X90 在相同来源场的真实迁移后有 X/Y 核心 34.523/37.434、前沿 42.295、最大相邻比 1.075200，峰跳 1.18e-5、相对质量缺损 2.20e-16、值域越界 3.22e-9，真实迁移和 post-transfer flow 均通过（[请求时刻配对审计](evidence/requested_alternative_transfer_tau11932_20260913.json)）。将 X90 仅在隔离研究分支的这一次请求中置于首位，原生推进到下次网格请求 τ12.171527；主轨道 X82 的下次请求为 τ12.083839。相应间隔为 0.239351 与 0.151663，X90 增加 0.087688 canonical 时间，或 57.8%（[隔离续跑数据](evidence/alternative_x90_interval_20260913.json)）。该反事实分支**没有**写正式 checkpoint 或结果、没有证明原始轨道等价，更没有验证长期误差或大箱 Profile。

在随后独立的第37、38次真实请求，同节点级拟合寿命排序均保留原候选1；第37次的绝对寿命预测明显偏长，说明该估计目前只能作为候选相对次序的研究依据。跨节点级虽可改善瞬时相邻比，也必须计入更多节点的每步/LU 成本。细节见[后续请求留出检验](AMORTIZED_MESH_LIFETIME_HOLDOUT_20260913.md)。

## 当前隔离测试与下一版决策依据

`grid-v6` 只加入**影子观测**，没有替换原网格触发、硬停机、安全因子、迁移门槛或 C 规则。每个真实接受步用连续二次峰值 X 处的四列局部 PCHIP 计算 Y 核心宽度、格数和同窗预测，记录与原决策的分歧；观察异常只进入元数据，不否决原求解步。八个已验签冻结 checkpoint 上，局部 PCHIP 与全 X 轴 PCHIP 的核心格数及宽度误差均为零（机器表示精度内）；影子字段通过原有签名 checkpoint 读取（[冻结观察数据](evidence/continuous_vertical_shadow_frozen_20260913.json)）。隔离原生续跑 τ≈0.1→0.120492（12 步）、τ11.700399→11.720399（47 步）和 τ≈11.9→11.950060（123 步，跨第 35 次自动重布）的结果及末 checkpoint 均通过原生验证，三个窗口均有 0 次影子/原生请求分歧；晚期短续跑最大 Y 核心格数相对差分别为 1.1635%/2.0616%（[早期验收](evidence/shadow_native_early_20260913.json)、[晚期验收](evidence/shadow_native_late_20260913.json)、[跨重布验收](evidence/shadow_native_remesh_crossing_20260913.json)）。在与主轨道共同的 5 个自由步记录上，180 个数值历史字段逐值相等，第 35 次重布的完整事务账本也相等（[逐值比较](evidence/shadow_native_equivalence_20260913.json)；只排除隔离短跑特设的时间终点诊断及截断终步）。这些结果证明观察器在这些窗口不反馈数值方程，但仍不能证明应改变正式触发。

下一步应跨越数次真实触发、重布和同网格 epoch 记录影子分歧，再用冻结窗口的留出事件比较假触发、提前量、迁移失败率及每单位 canonical 时间的 LU/重布成本。候选排序应同时评估预计核心可用时间、X/Y 最弱核心格数、前沿格数、最大格宽比和真实迁移审计；只把满足节点预算、1.08 候选质量、外层 2 阈值以及守恒/规范门槛的候选纳入比较。第35次事务表明，稍高的合格网格比可能显著延长重布间隔；可试验以历史拟合衰减率估算候选寿命，仍用原保守最大割线作安全触发，避免把排序实验误作放松安全门。该策略必须在独立后续触发上留出验证，再作为新的注册版本从 `t=0` 重跑。当前「最优均摊」不能由单一事件唯一判定，也不能把瞬时最小格宽比当成长时间最优。

主 H8 和 version-5 原生长跑保持原代码与原配置继续运行。若实验支持修改正式预测器或排序，应作为新的注册策略从 `t=0` 全程重跑并作较大物理箱、空间/时间网格的匹配比较；不能把晚期孤立续跑替代这一步。
