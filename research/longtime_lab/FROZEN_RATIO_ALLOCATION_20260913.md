# 冻结时间数据驱动的自动网格分配（2026-09-13）

目标是从原始 `t=0` 自动运行到足以检验强奇异性 Profile 的长时间，期间根据已接受场自动重布网和按方向增点，不靠人工暂停。这里用原生 checkpoint 的严格配对 `rho/x/y` 与维护的 7 点导数提取核心、前沿，再在既有候选网格族上比较每轴全套质量门和最大相邻单元比。冻结分析不做 Poisson LU、场迁移或 PDE 推进；“通过”仅指几何可提出，不能冒充原生重网格成功。

## 自动算法的具体选择规则

在每个受信接受步，由同一个原生场估计 X 核、Y 核和 X 前沿；用本次网格 epoch 内的宽度/核心单元衰减包络预测下一次审查前所需单元数。触发后对当前节点级以及方向上单调增长的节点级作有限几何筛选。先淘汰不满足核心、前沿、九点以下对应模板、求积、曲率和比值门的轴；在同一节点成本下最小化两轴中较大的 `|Δ log h|`，从而把伸缩均摊到相邻单元。跨节点级先选择满足预测余量的**最低成本**级别，若同成本有方向选择，则优先降低瓶颈轴的最大比。真实场迁移必须按既有事务门逐一验收，失败不得改动源场、源轴或时钟。

这给出符合数据的方向序列：τ≈4 必须先加 X；τ≈7.4 若尚有核心余量，应暂用 641×321，避免提前付出 961×321 的求解成本；当 X 比值余量或预测核心数逼近硬门时，加 X 而非加 Y。τ≈11.67 的旧冻结源先尝试同节点扩展搜索，再准备 X 增点作为后备。这个规则需要在 version-5 运行控制器中实现并通过真实 `t=0` 轨道，不把本文件当作已部署行为。

现有 version-4 族只到方向因子 3，且 `maximumTotalNodes=310000` 被配置固定；它即使在 961×321 上成功，也不能保证随后继续。完整无人干预运行需要在零时刻登记资源上限，在到达当前族末端前**自动产生更大方向节点级**，并保留参考根轴、锚点、箱、单调增长与 checkpoint 重建契约。任何有限 RAM/节点上限都不能保证任意接近真正的无限时间；若格宽持续缩小，资源会成为明确的停止边界。`maximumAdjacentGridRatio=2` 当前只控制已接受网格的光滑度停机；候选仍受 1.08 和其他数值门约束，不能以放宽到 2 掩盖模板或求积失败。

三个研究脚本 `audit_frozen_mesh_ratio.m`、`audit_frozen_mesh_candidate_levels.m`、`audit_frozen_capacity_v5.m` 复现上述无 LU 结果。它们分别读取原 H8 可信 checkpoint 与旧版本停止前的原生 checkpoint，调用生产轴候选函数，保存 JSON 审计。下一步需对新网格设计做冻结场**完整迁移验收**，再在隔离代码上从原始 `t=0` 长跑；H8 的边界误差告警要求另做大箱、空间及时间步对照。
