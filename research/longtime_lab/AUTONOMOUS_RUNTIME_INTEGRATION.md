## 接口与事务

仅显式 opts.autonomousMesh 启用；缺省不增加配置字段，旧数值路径保留。
解析政策规定 32–256 的双向目标及严格关联阈值，固定 70 个横轴、4 个纵轴搜索，最多 3 个候选对。
纯规划器只读场、配对轴、rho*Dx 与不可变 base 轴，不调用研究代码或构造 LU。

initialize 在两时钟和步数均为 0 时选择网格并重新采样同一解析初值。
初选必须通过实际核心/前沿/轴质量/安全门；以接受轴冻结 baseX/Y、初始质量、值域与规范参考。
记录初选前后轴、原始零时间、custom_axes 算子表示及完整尝试审计，不创建新物理 epoch。

advance 继续唯一 RK 路径，在接受步计算纯 meshPlan；每个接受步复查。
当前 core<26 或同方向 core<32 且预测未来 .2 native canonical 时间内低于22时提出迁移。
预测仅使用同一次网格的已接受观察，至少4条；不能改动 C、PDE率、CFL或时钟。
高于当前目标时的预测不会触发同轴迁移；演化候选排除 unchanged，提交前另验证坐标确有变化。

solve 持有外层状态，在 advance 返回后移除旧 poisson 分解引用，再调用 applyAutonomousMesh。
实际迁移先用原 transfer，再审计配置/参考/时钟/节点数/箱不变、完整梯度峰值、质量、值域、
原生90%核心、前沿及全轴质量，最后才增加 remeshCount 并更新日志。
候选全部失败时保留来源场，以同一 ops.A 重建分解；记录实际失败，不计成功迁移或重置预算。
在规划阶段出现分辨率/容量/程序错误则返回上一接受步，程序错误与数值拒绝分开记录。

控制器记录通过的实际迁移审计和有界同网格趋势窗；metadata 被原生 checkpoint 签名覆盖。
新 validator 校验初选、交易计数与累计跳变、时钟、末窗和当前原生状态/结果的一致性。
启用此政策的算子均来自 custom 轴，因此恢复直接按保存轴建一次；历史无此政策的恢复分支保留。
