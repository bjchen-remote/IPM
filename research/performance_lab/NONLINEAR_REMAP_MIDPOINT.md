# 非线性背景重映射中点探针

研究入口 `ipm_perflab_verify_lawson_remap(newDirectory)`，单步候选
`ipm_perflab_lawson_remap_step`。仅允许不超过 65×65 的各向同性网格；没有修改
`+ipm`、注册时间格式或 checkpoint。参照解始终使用原 `ipm.solve`。

## 需要分开的三个问题

1. 连续方程中分离背景速度，不意味着现有 WENO 离散对速度可加。
   `transport(r,V)-transport(r,b)` 与 `transport(r,V-b)` 使用的 LF 分裂幅值、
   非线性权重和常量残差校正不同。实验直接调用维护的 `ipm.field.transport`
   测量差异，没有实现另一份 WENO。
2. 固定系数的插值 remap `R(h)r = I[r](X exp(-alpha h),Y)` 不等于离散指数
   `exp(h B)r`，即使它对连续输运足够准确。这里
   `B r = -alpha X D1 r`，`D1` 必须使用正时间极限选中的内向局部模板。
   它的第二个时间导数是
   `R2 r = alpha^2 (X D1 r + X^2 D2 r)`，通常不等于 `B^2 r`。
3. 非线性输运需要中间状态的系数或完整 RHS。只冻结起点的 alpha 再做对称分裂，
   不能由此声称非线性二阶。

背景分离动机参考 Mignone 等的 [orbital advection 原文作者稿](https://arxiv.org/pdf/1207.2955)。
该文的均匀方向平移与这里的非周期膨胀具有不同的散度和边界条件。
非线性系数冻结的阶数问题参考 Cai、Boscarino、Qiu 的
[CF-RKEI 原文 §2.2](https://arxiv.org/pdf/1911.12229)。这些文献的保守、稳定或
SLDG 性质没有移植为本研究点值插值的保证。

## 真 CF2 的独立解析核对

全线问题 `rho_t+a X rho_X=0`，`a=integral(rho)/sqrt(pi)`，从
`rho=exp(-(2X)^2)` 出发，有 `rho=exp(-((2-t)X)^2)`、`a=1/(2-t)`。
把状态表示为 `(a,beta)`，冻结线性算子 `C=diag(a,-a)`，则

```
yHalf = exp(h C(y)/2) y
yNew  = exp(h C(yHalf)) y
```

这是真正中点系数的 CF2；只用第一行的起点系数推进整步是 CF1。此核对使用精确
子流和解析场，先排除空间插值误差，不能充当离散 IPM 的验证。

## 保持原半离散方程的候选

探针采用 Lawson 显式中点，而不是把原全速输运换成余速输运。
在每步起点选择一个非负的 `alpha`，令背景 `B` 在这一步固定，并定义
`N(y)=F(y)-B y`；`F` 每次都调用原 `ipm.evolve.flow`，同时重算速度、规范与尺度。
整个状态包含密度和对数尺度/时钟，`B` 仅作用于密度，其余分量为零。

```
yHalf = E(h/2) (y + h N(y)/2)
yNew  = E(h) y + h E(h/2) N(yHalf)
```

若 `E(h)=I+h B+h^2 B^2/2+O(h^3)`，逐项展开得到
`yNew=y+h F(y)+h^2 DF(y)F(y)/2+O(h^3)`。
因此背景可以每步按起点状态选择；非线性二阶来自中点的完整 `F`，并没有冻结
中点物理速度或规范。`B` 的状态导数无需补入，因为同一步的余项保留了全部 `F-B`。

比较三种 `E`：

- `raw`：原 poly6 点值 remap。其局部缺损为
  `h^2 (R2-B^2)y/2`，固定空间下通常只有一阶全局时间精度。
- `corrected`：`E(h)r=R(h)r+h^2 (B^2-R2)r/2`，修正这个确定的二阶缺损。
- `generator_expm`：小网格逐行密集 `expm(h B)`，仅作为生成元指数的独立对照；
  不建议将其逐行密集运算移入生产。

该二阶展开是固定空间、`h -> 0+`、查询尚未越过下一个模板切换点的局部结论。
跨多个单元时的 remap 及显式修正不因此获得稳定性。`N` 仍含全速 WENO，余速
`V-alpha X` 的 CFL 不能代替 `N` 的稳定性分析。校正没有投影密度、P 或 C，
没有 restoring、滤波或削弱原网格/规范准入门。

## 证据位置与解释

## 完成的数值证据

非线性解析膨胀 CF1 阶数为 0.962/0.981/0.990，真正中点 CF2 为
1.960/1.980/1.990。原 WENO 在 uniform 17/33/65 节点上的速度可加性 Inf
缺损为 6.39e-3/2.30e-4/8.60e-6；直接 `B_remap+transport(V-b)` 对原 RHS 的
缺损为 1.28e-2/8.26e-4/1.92e-5。空间加密会减小这些误差，但固定空间的
`h -> 0` 不会消除它们。拉伸 2 的最粗 17×9 网格被原正求积准入门拒绝，未放宽门。

同一 33×17 半离散方程上，未经修正 remap 的最细时间尾阶降至 physical
约 1.08、exact-gauge 约 1.16；修正法保持约 2.00，逐行 `expm(Bh)` 对照也
给出同样二阶。三种推进的差商与原 `flow` RHS 的 Inf 缺损均随 h 减小，
physical 为约 1.27e-4→1.31e-8，exact 为 2.44e-4→2.45e-8（h=1e-3→1e-7）。

可信双网格验证有两组，所有原始终态/历史都保存。统一使用 `[-4,4]×[0,4]`
uniform 网格、Dirichlet-zero 椭圆边界、open 输运边界、advective-upwind 壁面及
`-exp(-X^2-Y^2)` 初值；候选与原生参考共享同一显式小实验配置。可信性是对
保存的这份冻结配置使用原 `trustedMask` 得出的，不是 H=1e6/Green 生产场景的准入。

## 跨模板切换的拒绝证据

原生 65×33 `ipm.solve` 在 tau=.0495 把活动二次模板中心从 .75 切到 .625。
P 从 .857239194890903 跳到 .858636300091776，差 .00139710520087288；
所有行记录的原始 `F+c_omega P` 都为 0，跳变除以 .00025 记录间隔却为
5.58842080349。原 `Dx`、密度帧及三个 RHS 单独保存；切换帧不是 checkpoint。

`quadratic_switch_native65_v2/switch_frames.mat` 中包括 tau=.04925/.0495/.04975
的 rho、rhoX、完整 RHS、维护装配得到的无幅值源 baseRhs，以及所有尺度率为零
的 physicalRhs、flow、Dx/Dy/config。每帧严格校验
`rhs == baseRhs+cOmega*rho`；完整开启 snapshots 的原生重放必须与原参照的
末态 rho 和全部 history 逐值相等。v1 是缺少单独 physicalRhs 的早期帧，只保留作历史。

跨事件的 tau=.128 比较中，65×33 原生 512/256 步参考差已经占最细候选误差
约 7.8%；候选误差非单调，没有二阶验收。49×25 该窗口没有切换，原生 P
漂移仅约 -1.9e-15。共同 .032 窗口的通过不能替代跨事件失败。

## 余项稳定性与下一步

`remap_residual_stiffness_v2` 直接对维护 WENO 取两档扰动的单行 Jacobian。
即使纯 `V=alpha X`、余速严格为零，65 节点的 `F-B` 谱半径仍为 5.60，
完整 F 为 7.56；两档 Jacobian 扰动的相对差为 1.65e-7。因此余速筛查的
10.19x 不能直接变成这个离散方法的稳定步放大倍数。

`remainder_limits_v1` 给出冻结余项的衰减模态显式中点必要限制：17/33/65 节点
对应原全速 CFL 上限约 5.71/5.34/4.57。65 节点临界 h=.35729，取两倍时
数值临界模态放大为 5，精确衰减仅 .0183。该限制只属于冻结线性化的余项 RK2；
不等于 Lawson 合成方法的完整非线性稳定边界。

实际 corrected Lawson 在两档全可信 exact-gauge 上只做了有界一步 CFL
.5/1/2/4 筛查；CFL4 的 rho 相对 Inf 差分别约 1.77e-4、2.31e-4。
多步验证使用前述固定 h/.128 或 .032 轨迹，并保存实际每步全速及余速 CFL。
尚未建立实际非线性 `F-B` 的普适稳定步限制，不能据单步有限或 1% 小误差门
宣布可长时间大步运行。每步包含两次演化 RHS，另有接受态 flow 用于可信诊断；
没有进行同精度/同质量的生产速度比较。
