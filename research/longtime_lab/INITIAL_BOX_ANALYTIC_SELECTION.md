# 三箱原始解析初值的纯网格初选

2026-09-09 的独立筛查完成：`[-8,8]×[0,4]` 和 `[-16,16]×[0,8]`
各自返回的三个候选全部通过纯解析网格门；`[-32,32]×[0,16]` 返回的三个候选
全部因实际横向核心少于 31 个单元而拒绝。没有构造 LU、计算流场或推进 PDE，
所以这不是三个箱的动态误差比较，也不证明前两个箱已通过完整原生初始化。

## 已有证据与本次范围

旧 `q512_comega_initial_box_screens_v4` 使用相同 `degenerate_primitive`、k=8，
但箱半宽为 281、1e3、1e4、1e5、1e6，网格为专用 1025×513 工厂，且检验初始 RHS
规范。`result/longtime/20260908_initial_box_axis_audit_v1.json` 证实：仅部分 x 平台
共同节点一致，全部内层 x/y 网格不一致。该结果不能替代本次小箱、321×161、v2
自动初选，更不能把初始规范率差或远场速度幅值改称边界误差。

此前只有小箱 `[-8,8]×[0,4]` 的真实原始 t=0 自动运行证据；没有找到本次三箱
的同一 v2 初选筛查。晚态 fresh-crop 对照从另一个物理 epoch 开始，也不能代替
这里的独立原始解析初值资格。

入口 `mesh_screen_initial_box_geometry(originalOptionsFile,outDir)` 读取
`probe_v4/run/degenerate_primitive.mat` 中真实保存的原始 `o`，固定 321×161、
target32/32 和 node cap110000，只改变预登记的箱边界并换成明确 version2 政策。
原始配置使用 uniform 分支；轴表达式与 `mesh.build` 中该分支完全相同，实际不调用
`mesh.build`。密度由维护版 `initialDensity` 重新计算，导数始终来自配对七点 `Dx`。

每箱调用一次现有 `plannedAxisPairs`，最多检查其原有 top3。候选上重新采样解析
密度，再测原生90%核心和前沿。原初选门为 core≥31/31、front≥20、精确±anchor、
全部原轴质量门以及 `referenceAxisFamily` 四成员完整质量；资源 mask 冻结为
`[true true true false]`。不计算安全因子、规范或率，不转移粗源场，不创建 checkpoint。
代码额外对已知解析 rho-x 做误差观察，但它不参与任何新验收门。

## H32 的具体失配

粗 uniform 网格 dx=.2，其节点峰位为 1.2。原生90%核心原始交点为
`[1.1268364777,1.6060396513]`；`meshFeatureIntervals` 使用
`max(单侧原始半宽,local_spacing)` 的规则，把短左半宽扩大到一个完整单元，
设计区间因此变为 `[1.0,1.6060396513]`，宽 .60603965。
候选重新解析采样后的区间为 `[1.0973255979,1.5787609201]`，宽 .48143532，
比粗测设计宽缩小 20.56%。原预测 Xcore34.76185 因此落到实际27.63098；
原31门正确拒绝了它。

这不能全部归因于 rho-x 的 FD 误差。粗源内窗 `[.5,1.8]×[0,1]` 的解析导数
相对 Inf 误差为1.473%，候选为4.22e-8；相对更大的设计误差来自欠分辨率下
单元宽度下限、峰节点定位和由它们构造的几何区间。
前沿还使用固定五节点平滑，因此粗细轴对应的物理平滑跨度不同：H32 的前沿
区间宽由1.27463532变为.38851025，预测62.3305单元、实际22.2223单元。
虽然仍过前沿20门，这个差异说明不能把粗源的区间覆盖预测当成重新采样的实际验收。

H8、H16 的粗源到候选横向核心宽变化仅为−.5657%、−.3395%；但前沿宽变化仍为
−14.79%、−39.48%。全部宽度/峰位/原始交点及逐候选差值保存在报告中。

后续可以另行预登记一个仅 t=0 的有界解析设计迭代：把拒绝候选上的新解析
几何作为下一轮设计观察，保持同一原解析公式、物理零时刻、原始参考轴和全部门，
直到真正选择初始轴后才冻结 family。它应有明确迭代/候选预算，并保留每轮失败。
这里没有执行或接入这个新方案，也没有通过增加 LU 预算或降低 core 门处理失败。

即使三箱都能纯初选成功，完整域误差资格仍需要原生初始化/RHS、相同物理终点的
独立从零运行、时间误差和内层空间误差控制。由于这些箱的最终内层节点不同，
直接比较轨迹的差异同时包含截断与离散误差，不能自动解释为纯边界误差。
