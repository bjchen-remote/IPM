# 从零到长时的自动网格：设计要求与已知失败

用户要求的终点是：用原始解析初值，从物理 `t=0` 启动一次冻结规则的 `ipm.solve`，由程序自行观测、选轴、增点、迁移和检查，稳定达到长时间。中途人工更换候选列表、网格、源码或参数的续算可以帮助研究，但不满足这项验收。安全保存并停止也不等于完成。

完整失败记录见 [故障图谱](AUTONOMOUS_MESH_FAILURE_ATLAS.md)；本页只保留对最终设计有直接影响的结论。

| 实际遇到的问题 | 对自动规则的要求 | 当前证据与缺口 |
|---|---|---|
| 大初始箱的均匀粗格看不清初值核心；H64/H128 原初选没有候选，H32 几何预测与实际解析采样不符 | 将初始观测格与求解格分开；仅在原始零时刻自动提高已知解析初值的观测分辨率，再在实际候选格上验证 | 显式一次观察回退已维护、原生短程/恢复及全套通过；H64 从零长跑使用一次回退后自行继续 |
| 原固定节点数在晚期耗尽，增加预算后可以继续；方向需求并不同时出现 | 事先冻结按方向增长的参考族、资源上限及单调迁移规则，每个成员保留独立候选预算 | v2 的两个自然增长及原生恢复已实际通过；八成员 v3 仍为独立候选，factor3 两方向实际算子资源测试已过，原生演化仍待测 |
| 旧70项在裁箱step9205及原H8未保存11050请求全拒；接受态9205/11049同N、同箱仍存在合格新参数 | 不能把有限枚举失败解释为网格不存在；按构造约束自动细分搜索，保留原规则优先级与总预算 | 分层规则在330项处找到合格对，完整冻结场也通过；纯模块通过旧结果不变、500项耗尽及单位协变；9205真实迁移已过；v4已接入独立候选并通过无LU测试，实际从零演化仍待测 |
| H64 两次早期增长由 Y 预测触发，单步核心计数下降放大最大割线；H8 也有频繁预测触发 | 保留原始计数、拟合/最大割线端点和各目标成员拒绝原因；先复现，再比较新的连续宽度观察或预测规则 | 已有真实配对端点；旧已提交事务未保存完整 axisReport，不能确定较小族具体拒绝原因。尚未修改预测公式 |
| 候选几何核心数不保证插值后的真实核心、峰值和前沿；迁移可累积误差 | 几何提案、完整场预检、原生迁移验收分层执行；失败原子回退；记录累计实际峰跳 | 原生迁移门保持。9205新搜索首个原生事务已过全部原门及签名读回；11049目前只有完整离线证据，二者均不替代组合策略的自然演化 |
| 增长族的旧持久化摘要只有全局候选序号，不能逐级证明预算与次序 | 每次真实尝试保存目标级别及该级局部序号，并在读回前核对合法顺序/每级上限 | 独立纯负例复现了审计缺口，未观察到运行期超额。v3 独立修订已通过该反例及新的正/反测试；旧 v1/v2 文件不改写 |
| 固定规范箱对应的物理覆盖随尺度缩小；网格加密不能消除非局部远场误差 | 分别检查核心分辨率、物理域覆盖、时间误差和域敏感性，不能只盯峰值或当前 cell 数 | A/B、A/C 固定物理窗口科学门仍失败；原始t0全边界补偿已在H8/H32完成实际固定算子测试，显著减小初始率的箱差；尚无演化闭合资格 |

网格观测与控制只决定何时提案、用哪些实际轴及是否接受，不进入 `c_l/c_omega/c_r` 或时钟速度。C 保持原 `exact_gauge_no_feedback_v1` 代数规范。未知演化场不得用原始解析初值在箱外补填。

每次增长的可用内存必须由实际算子测量支持。节点总数相近不代表两个方向或两个箱的 LU 峰值相同；纯几何资源 mask 也不是内存认证。目前最多同时运行两条大型 LU 任务，候选改动在独立冻结副本测试，运行中的源码不修改。

验收需要同时具备：完整原始零时刻来源；途中无人工改规则的可信接受步链；网格/场/历史/快照配对；真实迁移与严格恢复；到预登记长时终点；独立网格、时间和物理域误差证据。现有原始 t0→τ8 一次运行证明了一个有限时段的自动性，正在运行的 H64 大箱实验与后续候选继续扩展这项证据，尚未达到最终验收。
