# 完整 Green 外尾边界迹：纯积分验证

2026-09-09。两种独立求积方式及512阶追加检查支持当前实现的**完整
外尾 Dirichlet 迹**公式。它不是把内点 xy*A/H 展开套到人工边界。
制造源、尺度协变和模板复用均为纯积分测试，没有求解或推进 IPM。
最初32/64/128/256阶试验未通过全部门，失败记录原样保留。

## 函数与精确积分对象

调用：

```matlab
[trace, info] = ipm_accellab_green_full_tail_trace(query, H, ...
    method='radial_analytic', order=256);
```

query 为 N×2 实际坐标，盒为 [-H,H]×[0,H/2]。右/左/上/下四条完整
边界按原节点数打包的模板见报告的 unitLeadingTemplate；helper 也
支持盒内查询。源为正象限盒外的
`Omega_infinity = x^7/(x^8+y^8)`，使用双奇镜像，并假设 kappa=1。
它是一个**领先外源模型**，尚不是精确 k8 初值的整个外尾，也不代表
未知 t>0 演化源。后续原初值控制须明确补入二者的差。

完整核等价写为

\[
G(q,S)=\frac1{4\pi}\log\!\left(1+
 \frac{16q_xq_y\xi\eta}{|q-S|^2|q+S|^2}\right),
\quad q_x,q_y,\xi,\eta>0.
\]

代码用 log1p 避免远端对数相减；负x目标由双奇镜像定向。x=0 或
y=0 的迹根据核恒等式精确为0，在积分前返回，并未投影任何演化场。

第一方法在原点极坐标中把领先源的径向积分解析完成：源与面积元
合起来是 f(theta) dr，四个 log quadratic 用

`F_b(r)=(r-b)log((r-b)^2+k^2)-2(r-b)+2k atan2(r-b,k)`

组合，其无穷上限的组合是 `2*pi*(k_y-k_direct)`。k 用叉积绝对值
计算，避免 `sqrt(|q|^2-b^2)` 在对齐方向消去。角区在盒角方向和
目标射线分割；靠近目标的角端点采用平方映射。

第二方法以目标q为极点，逐射线计算离开矩形与离开正象限的交点，
只积分二者之间的外区。有限径向区间使用平方映射，无穷区间使用
`s=s0+(u/(1-u))^2`。源点贴近边界目标时的 `s*log(s)` 可积奇异由
该坐标和映射处理；角区依四角方向切分。它不调用第一方法的径向
原函数。源按实际物理坐标 S/Cx 评价后乘 Comega/Cx，也用来独立
核验尺度变换。

## 制造源、边界误差单位与模板成本

制造扰动取盒外 `delta Omega=d_x[x²/(x²+y²)^(3/2)]`，为 -2次齐次。
在 H=4/8/16/32 同比例边界点上，完整扰动 psi trace 应为 H^0，而非
固定内点率的 H^-2。本轮四组迹逐值相同；第一遍扰动求积末级变化
6.68e-14，追加后8.08e-16。它验证这项积分缩放，不证明真实演化余项界。

对 `Omega_infinity+.2*delta Omega`，Cx=.7/1/1.7 与
Comega=.6/1/1.8 九组重新评价物理源、盒和目标后，使用
`psi_physical=psi_computational/(Cx*Comega)` 恢复的最大 scaled 差
7.77e-16。线性制造源组合差5.00e-16。完整边界与内点 `xy*A/H`
近场展开的最大差除以H为 **.0174771**，证实二者不能在全边界混用。

固定计算几何下的领先源模板满足 `b_tail=Comega*b_tail_unit`。
用Comega=.125/.7/1/2重新做完整二维积分，与标量复用比较均在原门内；
原解析模板对512独立参考的 scaled 差6.57e-14。

42个完整观察边界查询的模板重建中位成本 **4.22ms**；7批、每批1000次
标量乘加中位为 **.187微秒/次**。全部批次（含首批JIT成本）都保存。
已有边界在这个计时中是明确标记的合成数组，计时只说明预计算/复用
的操作成本，不是生产895/1025网格或完整RHS加速证据。

原unknown evolution余项若为 O(Comega*Cx*M/R²)，完整人工边界迹一般
是 O(Comega*Cx*M)，边界速度是 O(Comega*Cx*M/Hc)；只有固定内部
锚点率才有 Hc^-2。当前实现没有用后者替代全迹误差预算。
