# 原始 t0 完整 Green 外尾：真实固定算子结果

两组真实试验显示：只向原 Green Dirichlet 边界迹加入已验证的**精确解析初值全外尾**，再用同一离散 Poisson 因子求速度、重新计算原规范，锚点长度率的变化与独立连续外尾积分一致至1e-9以内。加尾后的 H8/H32 长度率绝对差缩小约253倍；剩余差几乎就是原来“原生盒内计算减精确盒内积分”的差。该结果支持在固定算子上识别这份已知外尾贡献，但没有认证全部空间误差，也没有证明 t>0 外尾闭合。

原始实际结果未改：`original_t0_tail_root_launcher_v1/native_A_H8` 与 `native_H32`。每组321×161，**一次 build、同一 LU 两次 Poisson、0 PDE**；原生初始率、完整 RHS 重组、rho/Omega/规范参考与初始快照配对门均过。原底墙、角点、镜像对称保留。绝非直接给 c_l 加 A/H。

## 1. 精确对象和可分离的三项

本次身份尺度初值为 rho0=log(1+x^8/(1+y^8))/8，Omega0=x^7/(1+x^8+y^8)，双奇源正象限盒D_H=[0,H]×[0,H/2]，transport anchor a=1。此前独立求积得到该解析初值全半平面的长度率比较值

`C_inf = 0.4884629072222951`。

令 I_H 为精确解析源的连续盒内锚点积分，T_H 为精确全外尾锚点积分，N_H 为原生初始 c_l，Delta_h 为实际加完整外尾迹后经过离散 Poisson、速度导数和原规范得到的 c_l 变化，则

`(N_H + Delta_h) - C_inf = (N_H - I_H) + (Delta_h - T_H)`。

这里第二项是**这份光滑外尾的离散 harmonic 锚点响应误差**；第一项合并原 FD 源、原生 Green 节点求积/阈值/压缩、椭圆离散、边界处理及初选网格等因素。第一项不能改名为纯 Poisson 误差。恒等式是数值分项核对，不是对所有内源误差机制逐项完成的因果识别。

相对于连续全域比较值，加尾后的 c_l 偏差仍为−0.05127%/−0.01881%。H32 的锚点 harmonic 响应误差反而略大于 H8，不能凭这两种不同轴推出通用网格阶。实际原生 Omega 与解析 Omega0 的节点 Inf 差在固定内区[0,2]×[0,1]为3.30e-8/8.75e-8；全盒为3.42e-7/4.45e-6。它们只量化该 FD 源分量，不能将其直接换算成速度误差或解释全部 c_l gap。

## 3. c_omega 的变化更小，不能套用 A/H

| 量 | H8 | H32 |
|---|---:|---:|
| 原生 c_omega | .1259367301814702 | .1254273036058889 |
| 加完整外尾后的 c_omega | .1251932907760682 | .1254139514932390 |
| 实际变化 | −7.43439405402e-4 | −1.33521126499e-5 |
| 连续解析峰规范的外尾变化 | −7.45108574524e-4 | −1.21129477950e-5 |
| 原生变化−连续变化比较 | 1.66916912e-6 | −1.23916485e-6 |

最后两行只比较外尾响应，**没有算出全域精确 c_omega 真值**。原规范使用离散三点二次峰、维护输运和原 WENO 组合；不能把连续公式替代其真实瞬时代数规则。

连续解释如下：壁面原重标度方程为

`Omega_tau = -(u1+c_l*x)*Omega_x + (c_omega-c_l-u1_x)*Omega`。

解析初值唯一非退化峰 a*=7^(1/8)=1.2753731068584542，于该峰 Omega_x=0，保持峰幅的连续规范给 c_omega=c_l+u1_x(a*,0)。对外尾，设 D=(x−xi)^2+eta^2、O=(x+xi)^2+eta^2，则

`delta u1(x,0) = -integral 4*x*xi*eta*Omega0/(pi*D*O)`，

`delta u1_x = -integral [4*xi*eta*Omega0/(pi*D*O)]*[1-x*(2*(x-xi)/D+2*(x+xi)/O)]`。

因此连续尾响应为 T_H(1)+delta u1_x(a*,0)。领先项 delta u1≈−(A/H)x 同时产生 delta c_l≈A/H 和 delta u1_x≈−A/H，二者抵消；c_omega 的领先变化因而是更高阶多极项及实际离散效应，而不是 A/H。本次原生二次峰位置分别1.2755634172/1.2755918029，本来也与解析真峰不同。约1e-6的剩余 c_omega 响应差混合了峰泛函、输运离散与导数响应等因素；H32 连续尾变化很小，不能用相对该小差的百分比夸大完整 c_omega 误差。

## 4. 剩余跨 case 差

原 c_l 的 H32−H8 差为0.0401753164365，加尾后为0.000158590890675；绝对差缩小253.3268倍。相对于各自 H8 值，跨 case 差由9.23743%降到0.032484%。固定共同21×11内区上的速度向量差 Inf 从0.18988485降至0.0008507106；相对 H8 速度 Inf 从29.6785%降至0.109077%。这两个 case 的轴、内部 FD 源、Green 离散等仍不同，不能将剩余量或缩小比例当作已排除所有混杂后的纯箱因果结论。

c_omega 的跨 case 差则从−0.000509426576变为+0.000220660717，符号改变且没有像 c_l 一样接近重合。这也说明修复大部分初始锚点率敏感性，不等于已经修复全部规范与形状演化敏感性。

全边界外尾 psi Inf 为1.80337/7.21347，随 H 大致增加4倍；相应固定内点速度/应变贡献减小。完整人工边界迹与固定内点 A/H 展开有不同尺度，不能把 x*y*A/H 的近场近似当成全边界数据。实际试验使用的是完整迹。
